# Hexo / Vivia migration archive

These files are retained for reference only and are not imported by the Astro site.

- `site-overrides.css` contains the former caption, callout, rich-card, and code-block overrides.
- `rich-content.js` contains the former Hexo renderer hooks.
- `default-light.js` contains the former theme-mode hook.
- `_config.yml` is the former Hexo site configuration.

In particular, the old code-block CSS is intentionally **not** enabled in Fuwari. Fuwari's native Expressive Code styling remains unchanged.
